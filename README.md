# 番茄钟 · 应用监管 (Pomodoro Guard)

一个桌面小工具，把两件事合在一起：

1. **番茄钟** —— 可自定义工作 / 短休息 / 长休息时长与周期，倒计时结束自动切换阶段并提示。
2. **应用监管** —— 指定一批程序名（如 `chrome.exe`），在**工作阶段**按固定间隔检测它们是否在运行，
   **一旦发现立即强制关闭**并写入日志（默认只在"工作"阶段执行，休息/暂停/未开始不关闭）。

## 架构

```
pomodoro_guard/
├── pomodoro_core.py     # 核心逻辑（UI 无关）：进程检测/关闭、番茄钟状态机、配置、解码
├── presence.py          # 核心逻辑（UI 无关）：摄像头人像在场检测（人脸+人体组合，后台线程）
├── stats.py             # 核心逻辑（UI 无关）：专注时长统计（SQLite：段记录/日周月聚合/streak）
├── pomodoro_guard.py    # PySide6 界面层（展开模式为 设置·监管 / 统计 两页导航）
├── make_icon.py         # 生成 exe 图标
├── build_exe.bat        # 一键打包脚本（PyInstaller）
├── requirements.txt     # PySide6（必需）+ psutil/opencv（可选）
├── face_detection_yunet_2023mar.onnx  # 人脸检测模型（~230KB）
├── person_det.onnx      # 人体检测模型（YOLOv8n，~12MB，低头/背对镜头兜底）
├── pomodoro_guard_stats.db  # 运行时统计库（自动生成）
└── README.md
```

界面层与核心逻辑分离：`pomodoro_core.py` 不依赖任何 GUI 框架，可以单独测试、替换界面。

## 安装与运行

```bash
pip install -r requirements.txt     # 安装 PySide6（psutil/opencv 可选）
python pomodoro_guard.py            # 运行
```

> opencv-python-headless 与模型文件 `face_detection_yunet_2023mar.onnx`（人脸）、
> `person_det.onnx`（人体）用于「摄像头在场检测」；任一缺失时该功能自动降级
> （人脸/人体两个模型相互独立，缺失其一则只用另一个），其余功能不受影响。

> **Windows 长路径报错**：如果 `pip install PySide6` 报 "No such file or directory ... .cpp.obj"，
> 是因为系统未开启长路径支持（常见于 Microsoft Store 版 Python 的深层用户目录）。
> 解决办法二选一：
> 1. 装到短路径：`pip install PySide6 --target C:\pyside6`，运行时设 `PYTHONPATH=C:\pyside6`；
> 2. 以管理员身份运行 `reg add "HKLM\SYSTEM\CurrentControlSet\Control\FileSystem" /v LongPathsEnabled /t REG_DWORD /d 1 /f` 后重启。

## 使用说明

### 番茄钟

- 界面为**深色主题**：所有前景/背景色都在样式表里显式指定，不受系统深浅色主题影响
  （系统深色模式下文字也不会"白字配浅底"）。
- **Windows 11 22H2+ 自动启用系统「云母」(Mica) 背景**，与资源管理器/设置应用同款材质；
  旧系统或 DWM 不可用时自动回退为纯深色背景，不影响功能。
- 「番茄钟设置」里调整工作时长、短休息、长休息、长休息间隔（每几个番茄进一次长休息），点「应用设置」生效。
- 「开始 / 暂停 / 跳过 / 重置」控制计时；阶段结束自动切换（可取消勾选"自动开始"）。
- 「窗口总在最前」勾选即生效，可让倒计时浮在最上层。
- **窗口显示模式**：主窗口有「收起 / 展开」两种模式——收起模式只显示番茄钟
  倒计时与控制按钮（开始/暂停/跳过/重置/展开面板），展开模式再显示全部内容
  （两页导航：「设置·监管」与「统计」）。打开程序**默认收起**；点「展开面板 ▾ /
  收起面板 ▾」手动切换；每次展开**默认落在「统计」页**。进入休息阶段时程序
  **自动收起**并把窗口移到屏幕**右上角**（距边缘 24px），方便配合休息遮罩使用；
  程序只自动收起、**从不自动展开**，展开始终由用户手动点击。
- 「状态切换提示音」（默认开启）：阶段自动切换**或手动「跳过」**时都会播放提示音——
  开始工作=上行双音，短休息=下行双音，长休息=三连音；窗口在托盘后台时同样会响。
  音效在本地合成，无需任何音频文件。
- 「休息时全屏遮罩提醒」（默认开启）：进入休息阶段时全屏覆盖**所有屏幕**，中央显示
  "请立即看向6米以外的窗外物体，并眨眼10次！"，强制放松双眼。遮罩无边框置顶、
  拦截鼠标点击、无法被 Alt+F4 关闭；**只有本软件主窗口悬浮在遮罩上方**（未勾选
  "窗口总在最前"时程序会临时强制主窗口置顶，休息结束自动恢复原状态）。
  休息结束（自然结束或手动「跳过」）遮罩自动关闭；想提前结束休息，可通过主窗口
  或托盘菜单「跳过」。取消勾选即关闭该功能，设置自动保存。

### 应用监管

1. 在输入框里填程序名，例如 `chrome`（自动补全为 `chrome.exe`）、`notepad.exe`，回车或点「添加」。
2. 勾选「启用监管」，程序会按「检测间隔」周期扫描；**默认只在"工作"阶段**（计时进行中）执行，
   休息、暂停、未开始（重置后）都不会关闭任何应用——取消「仅工作阶段监管」可恢复任何时刻都扫描。
3. 发现目标进程在运行 → 依次尝试 `taskkill /T` → `Stop-Process` → `psutil` 强制关闭并记录日志。
4. 勾选「进入休息时强制关闭监管应用」后，每个工作阶段结束时还会主动清场一次（仅在勾选时生效）。

### 摄像头在场检测

- 「摄像头在场检测」（默认开启）：用摄像头判断人是否在屏幕前，采用**人脸＋人体组合检测**——
  **人脸或人体任一检测到即算"人在"**。低头写作业、背对镜头时人脸不可见，但人体检测（YOLOv8n）
  仍能命中；只有两者都检测不到（人离开座位）才算"不在"。摄像头**仅在需要时启用**
  （工作计时中 / 休息遮罩显示时），空闲自动释放（指示灯熄灭）；检测频率 5 秒/次，分辨率 640×480。
- **专注时段**：连续约 15 秒（设置里可调 5–120 秒）检测不到人 → 自动**暂停**计时，
  日志记录；人回到摄像头前 → 自动**继续**。**手动暂停不会被自动恢复**；
  人不在时手动点「继续」允许，但若仍无人会在宽限期后再次自动暂停。
- **休息时段**：人在 → 遮罩保持打开；人离开连续超过 **1 分钟（固定值）** → 关闭遮罩窗口，
  本次休息内不再重新打开（每次新的休息阶段开始，遮罩照常打开）。
- **降级**：无摄像头 / 被占用 / 权限被拒 / 模型缺失 / 未装 opencv 时，该功能自动停用，
  计时与遮罩行为与关闭时完全一致，日志会提示原因。
- 摄像头启用时指示灯常亮属正常现象；状态栏显示"摄像头: 人在 / 人不在 / 不可用 / 关"。
- **⚠️ 软件所在路径不能含中文**：OpenCV（cv2）在 Windows 上无法打开含中文的文件路径
  （其 C++ 底层用窄字符文件接口）。若把软件放在 `桌面\番茄钟` 这类中文目录下，
  人脸/人体模型会加载失败，症状表现为：**摄像头灯亮、Windows 显示"正在使用摄像头"、
  状态栏显示"摄像头: 不可用"，但永远检测不到人**（E 盘等纯英文路径则正常）。
  解决办法：把文件夹放到纯英文路径（如 `C:\PomodoroGuard`、`D:\Apps\PomodoroGuard`）
  或改名为英文；详见"打包成免安装 exe"一节的说明。

### 数据统计

- 展开模式下切到「统计」页查看：**专注总时长**（工作阶段运行中累计，暂停/休息不计入）
  以"X 小时 Y 分"大字显示，面板打开时**每秒实时跳动**；顶部「今日 / 本周 / 本月 / 累计」
  四档切换。
- **柱状图**（自绘，无需图表库）：本周=近 7 日、本月=近 30 日每日时长，累计=按月；
  柱顶标注数值、鼠标悬停显示精确时长；对应档无数据时显示占位文案。
- **连续专注天数**：当天完成 ≥1 个**自然结束**的番茄（跳过不算）即计入，中断一天归零。
- 数据**实时落库**（SQLite `pomodoro_guard_stats.db`，与程序同目录）：阶段结束、跳过、
  程序退出时写入，中途崩溃不丢；「清除历史数据」需二次确认。
- 统计口径补充：手动暂停/摄像头离开暂停的时间不计入；跳过的阶段其已运行时间照常计入。

### 系统托盘

- **左键点击托盘番茄图标**：显示 / 隐藏主窗口（隐藏后从任务栏消失，后台继续计时与监管）。
- **右键点击托盘图标**：弹出精简状态菜单（阶段、剩余时间、本轮番茄、监管状态），
  以及 显示/隐藏主窗口、开始/暂停、跳过、重置、退出。
- **关闭按钮(X) 和最小化**：隐藏到托盘后台运行，真正退出请用托盘菜单的「退出」；
  托盘不可用时会退回原来的「关闭=退出」行为。
- 托盘悬浮提示实时显示当前阶段与剩余时间；窗口隐藏到托盘时，阶段切换只响铃不弹窗。

### 设置持久化

- 监管列表、检测间隔、番茄钟时长与所有开关都会自动保存到脚本同目录的
  `pomodoro_guard_config.json`，**下次启动自动读取**；增删监管项、修改设置即时写入。
- 设置文件损坏或不可写时程序会降级为默认值并在日志提示，不影响运行。

## 打包成免安装 exe（PyInstaller）

目标机器**不需要安装 Python 运行时**：

```bash
pip install pyinstaller PySide6     # 构建机装依赖
build_exe.bat                        # 一键打包（自动生成图标 + PyInstaller）
# 产物：dist\PomodoroGuard\PomodoroGuard.exe
```

- **文件夹模式（`--onedir`）** + 无控制台（`--windowed`）：运行时**不会向临时目录解压**，
  启动秒开、杀软误报少。分发时整个 `dist\PomodoroGuard` 文件夹一起拷，不要单独拿 exe。
- **⚠️ 放置/解压路径必须为纯英文**：OpenCV 无法加载含中文路径下的模型文件，
  软件放在中文目录（如 `桌面\番茄钟`）时**摄像头在场检测会失效**（症状与原因见
  "摄像头在场检测"一节），其余功能不受影响。分发到目标机器时请使用英文目录名。
- 已排除 QtQml/QtWebEngine/QtNetwork 等未用模块，减小体积。
- 摄像头模型 `face_detection_yunet_2023mar.onnx`（人脸）与 `person_det.onnx`（人体）
  已自动打包进 `_internal`（也支持放 exe 同目录替换）。
- 配置文件 `pomodoro_guard_config.json` 生成在 **exe 同目录**（打包后自动改用 exe 目录，不会写进临时目录）。
- 单例锁在系统临时目录（`%TEMP%\pomodoro_guard_qt.lock`），崩溃残留会自动清理。

## 补充说明

- 关闭普通用户进程无需管理员权限；如果目标程序**以管理员权限运行**，关闭会失败，
  日志会给出提示。此时可点击「**以管理员身份重启**」按钮（触发 UAC 提权重启）后再试。
- **受反作弊保护的程序**（如原神 yuanshen.exe / 反作弊驱动 mhyprot2）在游戏运行期间
  从用户态**无法强制结束**（taskkill / Stop-Process 均报"拒绝访问"），提权后通常也不行，
  这是反作弊设计使然；请通过游戏内退出，或关闭反作弊相关服务后再操作（有风险）。
- 同一目标连续失败时自动进入 **60 秒冷却**，期间不再反复尝试，避免日志刷屏；
  手动删除该目标会立即清除冷却状态。
- 每次关闭后都会复核进程是否真的结束，失败原因会原样写进日志，不会谎报成功。
- 子进程输出按系统代码页自动解码（兼容中文 Windows 的 GBK），日志不会出现乱码。
- 日志里每一行都有时间戳，方便回溯。

## 进程检测后端

自动按可用性选择：`psutil`(最高效) → `PowerShell` → `tasklist/taskkill`，启动日志会显示当前后端。
扫描与关闭全部在**后台线程**执行，不会卡住界面；检测为**批量一次调用**。
